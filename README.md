# komplan.app

Führungsorganisation, Kommunikationsplan und Kommunikationsskizze (Fb Fü 76/77, FwDV 800 Anlage 1) im Browser, auf einem gemeinsamen Datenmodell. Teil der Werkzeugfamilie einsatz.tools. Läuft ohne Server, alle Daten bleiben auf dem Gerät.

Status: Planung. Architektur in [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), Datenmodell in [docs/DATENMODELL.md](docs/DATENMODELL.md), Festlegungen in [docs/DECISIONS.md](docs/DECISIONS.md), Auftrag in [docs/AUFTRAG.md](docs/AUFTRAG.md).
